## Proposed common boundary paragraph

> Mind owns memory and its internal execution records, including `work_items` and `stage_executions`; they are not a qualified general-purpose shared task backend. Relay is a candidate task/chat interface, but its existing todo/goal displays do not establish an authenticated shared task service. Control owns its oversight workflows, findings, approvals, and Control-specific audit and chat records. A Control approval records a bounded decision; no Mind record, event, or chat message authorizes execution. The authoritative shared task store, actor identity, board permissions, mutation/removal attribution, and durable task event/replay contract remain to be specified and verified separately. Control's operations freeze and all applicable integration gates remain in force; Mind G0–G7 are open.

This paragraph is a **proposal**, not a claim that the four source documents already say it or that the task contract exists.
