## 5. FINDING — two incompatible harnesses in the prior evidence

This is a correction to how the prior numbers were presented.

The prior milestone placed the GGUF baselines (5.0863 / 5.2827) next to the ternary
localization numbers (59.87 / 40.48 / 44,176) as if they were on one scale.

They are not. They come from two different harnesses:

| Harness | FP16 baseline | Used for |
|---|---|---|
| llama.cpp `perplexity_v2` | **5.0863** | GGUF FP16 and Q4_K_M controls |
| PyTorch / Transformers (bf16) | **12.0361** | All ternary localization numbers |

The ternary numbers must be compared against their **own** baseline of 12.0361:

| Variant | PPL | Ratio vs 12.0361 |
|---|---|---|
| FP16 (PyTorch harness) | 12.0361 | 1.00× |
| Attention only ternarized | 59.8700 | 4.97× |
| MLP only ternarized | 40.4843 | 3.36× |
| All four projections ternarized | 44,176.0520 | 3,670× |

**Consequence:** the previously stated "5.0863 → 44,176" comparison is cross-harness and
must not be used. Phase 1 must pin one harness as the reference and state which one.
